# Chirp Flatpak

A flatpak distribution of [CHIRP](https://chirpmyradio.com).

> [!IMPORTANT]
> For the app to fully function, adding your Linux user to the dialout group will be required in order for CHIRP to access serial ports. This is usually done like this: `sudo usermod -aG dialout $USER`

Special thanks to [KR4ERF](https://github.com/KR4ERF). [Their chirp flatpak](https://github.com/KR4ERF/radio.kr4erf.chirp.Chirp) came in real handy.
